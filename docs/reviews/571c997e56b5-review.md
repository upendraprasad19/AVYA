## Finding 1 — P1 — guard_without_its_mirror / missing_input

- **suggested-fix:** Recreate a covering index on `nutrition_log_items(food_id)` in a follow-up migration.
- **status:** fixed — `supabase/migrations/142_restore_nutrition_log_items_food_id_index.sql` (`CREATE INDEX IF NOT EXISTS idx_nutrition_log_items_food_id ON public.nutrition_log_items USING btree (food_id)`), covered by a new test in `disk_io_audit_cleanup_batch_test.dart`. **Founder-authorized separately in chat and applied live** (cloud_version `20260922043010`).
