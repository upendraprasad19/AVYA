# A turn that failed because the provider failed still cost the user a daily unit

The refund is the second half of the insert-first reservation: the reservation spends a unit BEFORE the model call (so a capped request never pays for Gemini), and `refund_quota` gives it back only when the model call failed for a reason the user did not cause. "Did not cause" is decided by the pure `refundableFailure` (`_shared/gemini.ts`), fed by a classifier of every no-reply Gemini body (`classifyNoReply`) and a STICKY `blockSeen` flag so one content block on any attempt keeps the unit spent. See the diagnose frontmatter for the writer/reader map, the mutation proof and the accepted residue.
