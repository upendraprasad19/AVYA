## Root cause

Measured on main 4e0637ae with the 2,304-plan audit and a temporary print in `rankedPool` (not committed).

- **The quad slot (OI-497 part 1).** Several leg days carry `MuscleSlot(Quads, subFocus: 'isolation', knee_dominant,
  isolation)` (`split_resolver.dart`). With no loaded quad isolation row at home, R3 (a)'s like-for-like reduction
  finds nothing; the fit key's guard was `slot.exerciseType == 'compound'`; the type key ties among the compound
  lunges and squats, `priority_tier` ties at 1, and `is_foundational` decides: E042 Walking Lunge.
- **Phase 1 (OI-497 part 2).** Key d (`phase == 1 && !foundational`) precedes the sub-focus, type and fit keys
  (c756b4's placement). The S1b-2 loaded versions are not foundational, so in phase 1 a foundational bodyweight row
  beat them.
- **OI-387.** A level choice in the data: G0355 was core at intermediate and advanced only.
