## Root cause

Writer: `scripts/library_batch_c2_removals_gen.js` marked E144 `alias: true`, so `applyAliases` in the importer wrote
`name_aliases: ["Reverse Lunge"]` on G3470 (a source row, rebuilt on every run, so this is its only writer). Readers: the
Hive client's `getByExactName` fallback (old plan rows) and, from OI-507 unit A, the coach tool's alias stage. The alias
policy "a removed name stays reachable as an alias of its replacement" was applied to a replacement that is a DIFFERENT
movement.

## Plan review

Three context-blind Sonnet rounds (`docs/plan-reviews/oi507-lunge-alias.md`). Round 1 found the planned importer stage was dead
code (G3470 is a source row), that the stored-reference claim was false (`user_progress.plan_json`), and the untracked test chain;
round 2 found the build order committed before a migration could exist and the missed `_markSeeded` mirrors and "others
unchanged" snapshots; round 3 converged with P2s. The author re-verified each P1 against the code or live data before applying it.
