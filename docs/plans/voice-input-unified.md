## 2. Design

**D1. `SpeechInputService`** (`lib/core/services/speech_input_service.dart`; `Provider<SpeechInputService>` named `speechInputServiceProvider`, overridable). The ONLY owner of the plugin (G1). Constructed with `engine`, `isWeb` (default `kIsWeb`), `platform` (default `defaultTargetPlatform`): tests override the provider with a fake engine and flip `isWeb`/`platform` (the VM's `kIsWeb` is const false). Pieces:
- `SpeechEngine` interface (`initialize`, `listen`, `cancel`, `changePauseFor`, `isAvailable`) with `PluginSpeechEngine` (wraps `SpeechToText()`, re-assigns `statusListener`/`errorListener` on attach) in the same file; the fake lives in `test/helpers/fake_speech_engine.dart` and **mimics the single result slot, the unattributed late events, and each native/web ordering of G4/G5** (final-before-`notListening`, `notListening`-done-error, `listening` emitted before and after `listen()` returns).
- ONE memoized in-flight `initialize` Future: `true` is cached; `false` is NOT cached on native (the user can grant the permission later), cached on web (unsupported browser). It installs the only `onStatus`/`onError`, forwarded to the BOUND session. Init options come from the pure `speechInitOptions({web, platform})`: `[SpeechToText.webDoNotAggregate]` only when `web && platform == TargetPlatform.android` (Chrome on Android duplicates results otherwise; an unknown web OS also resolves to android, harmless), plus `finalTimeout: SpeechInputTiming.finalTimeout`.
- **Wrap-and-map:** every engine call is wrapped; `SpeechToTextNotInitializedException`, `ListenFailedException`, `PlatformException` (`recognizerNotAvailable` -> `unsupported`), the web `initialize` throw and the literals `not supported` / `speech_not_supported` map to a classified failure, never an exception to the framework; each reports `ErrorTelemetry.recordNonFatal` with the CODE or exception TYPE only, never the transcript (G18).
- **Serialisation:** `begin` (quiesce + `engine.listen`) and `cancel` run one after another through ONE `SerialSlot` (ticket released in a `finally`). The wait for the `listening` status is OUTSIDE the slot, completed by `listening`, the start timeout, Stop, Cancel or dispose, so a tap on Cancel never queues behind a 15 s permission prompt.
- **Binding and the own-event rule:** a session is bound to the router synchronously just BEFORE `engine.listen` is issued (events before that go to nobody); after binding, a session drops everything except its own `listening` status and errors until it has seen that status (so a late final/`done`/`notListening` of the PREVIOUS listen, G1/G5, can never end or feed the new one). **In `starting` only permission, unsupported and engine-class errors are fatal; benign codes (`error_no_match`, `error_speech_timeout`, `aborted`, `no-speech`) are dropped there**, because the plugin drops a late error only while `isNotListening && _userEnded` and `listen()` resets `_userEnded` (`speech_to_text.dart:466,706`), so a late benign error of the PREVIOUS session would otherwise end the new one silently. A `listening` status with NO bound session (the prompt answered after a timeout, a stop while starting) triggers `engine.cancel()`: an ownerless hot mic is impossible.
- **Quiesce and settle:** the service tracks `engineActive` (true from the moment `engine.listen` is ISSUED, false on `notListening`/`done`, on web also at `onend`; it sees every status; `listening` is NOT the key, because on web it arrives only after the permission prompt, so a Cancel followed by a tap inside the prompt would skip the wait). `begin` waits for the engine to go inactive (armed BEFORE the `cancel` that provokes it) only while `engineActive` is true, capped at `SpeechInputTiming.quiesce`; otherwise it does not wait (a cancel on an idle engine emits nothing, G5). After a completed `engine.cancel()` the next `engine.listen()` waits at least `SpeechInputTiming.settle` (150 ms): on Android SDK 29 (`!recognizerStops`) `cancelListening` posts a `destroyRecognizer()` 50 ms later that nulls the single recognizer field (`SpeechToTextPlugin.kt:346-364,698-710`), and a late final of the cancelled listen could otherwise poison the plugin's `_latestResultType` for the new session (`speech_to_text.dart:470,680,693`). After the cap it proceeds. **One retry, time-based:** within the first `SpeechInputTiming.retryWindow` (1.5 s) of a session with no words, in ANY state, an `error_busy`/`error_client` (Android emits `listening` synchronously BEFORE the recognizer's own start, `SpeechToTextPlugin.kt:299-305`, so these arrive AFTER `listening`) or an exception thrown by a web `listen()` (InvalidStateError while the previous `abort()` is still ending, G4) restarts the session ONCE after the engine is inactive and `settle` has passed; a second failure ends it with the engine message. Every slot-held engine call is wrapped in `.timeout(SpeechInputTiming.engineCallTimeout)` so one hung platform call cannot wedge the slot.
- **A foreign active session** (a bug-class path: no screen shows two live mics) is ended through the normal end path with reason `preempted` (its words kept for its `onEnd`), and the new `begin` queues behind it in the slot. There is no separate drain.
- `speechListenOptions({required bool web})` (a function: the class is not const): `localeId: web ? 'en-IN' : 'en_IN'`, `listenMode: dictation`, `partialResults: true`, `listenFor: 60 s`, `pauseFor: web ? null : 5 s` (on web the Dart pause timer would start before the user answers the permission prompt, G4; the service applies `engine.changePauseFor(5 s)` on the session's own `listening` status, `speech_to_text.dart:514-527`, so a forgotten web mic still ends), `cancelOnError: false`. Native values equal today's.
- **`SpeechInputTiming`** (the ONE home of the constants; no `kSpeech*` siblings): `finalTimeout` 1 s, `endGrace` 1.5 s (native recognizer-initiated end without a final), `errorGrace` 400 ms (a trailing error after `done` with no words), `quiesce` 1 s, `settle` 150 ms, `retryWindow` 1.5 s, `toggleGuard` 300 ms, `engineCallTimeout` 5 s, `startTimeoutNative` 4 s, `startTimeoutWeb` 15 s (permission prompt), `listenFor` 60 s, `pauseFor` 5 s. The start timeout is armed BEFORE `engine.listen` is issued (Android emits `listening` before `listen()` returns, web after). A test pins `endGrace > finalTimeout`.

**D2. `SpeechInputController extends ChangeNotifier`** (`lib/core/services/speech_input_controller.dart`; local widget state like a `TextEditingController`; no `ref` inside; created by the host through `service.newController(onEnd: ...)`). **Three states: `idle -> starting -> listening`.** `starting` is set synchronously before the first `await`. `supported` reads `service.isSupported` (web: the probe result, taken at the host's first build; native: true until a tap fails).
- **ONE end path `_finish(reason, words)`:** latch (a second call is a no-op); set `idle`; stop the ticker and every timer; unbind; enqueue an idempotent `engine.cancel()` (EVERY end releases native/web state: the plugin's timers are cleared only by it, G1); call `onEnd(SpeechSessionEnd{transcript, reason, failure, empty})` inside a try/catch that reports the exception TYPE to telemetry and NEVER rethrows (a throw would propagate into the plugin's result chain and skip `_onNotifyStatus(_finalStatus)`, `speech_to_text.dart:698-701`); notify listeners only if not disposed; **no host callback (`onEnd`, `onListeningChanged`) is invoked for reason `disposed`** (the composer's dispose must not `setState` the screen); the session epoch bumps on EVERY `_finish`; a `toggle()` within `SpeechInputTiming.toggleGuard` of any `_finish` is ignored (a double tap on the mic must not land on Stop/Send). `failure` (`permissionDenied | unsupported | engine`, or null) and `empty` (an auto or benign end with no words) let each host show its message exactly once; nothing in the controller is sticky. **Every session that left `idle` gets exactly ONE `onEnd`, including `starting` failures and timeouts.** `reason` in `userStop | userSend | cancelled | auto | preempted | hidden | error | disposed`; `transcript` = the words on screen at that moment (final words if the platform just delivered a final, else `liveText`).
- **API:** `toggle()` (idle -> start; listening -> `stop()`), `stop()`, `send()`, `cancel()`, `endForHidden()`; `dispose()` (ends with `disposed` if a session is open; a continuation resumed after dispose re-checks the session epoch after EVERY await and never opens a mic); getters `state`, `liveText`, `failure`, `supported`, `isBusy` (`starting` or `listening`); `elapsed` is a separate `ValueListenable<Duration>` (1 s ticker, cancelled in `dispose`) so the tick rebuilds only the timer text. `cancel`, `endForHidden` and `dispose` act only on a session this controller owns (an idle host cannot kill another host's mic). A second tap while `starting` is ignored; in `starting` only Cancel is live (`cancelled`), Stop and Send are inert (they occupy the spot of the mic, and a double tap must not end the session it just started). A tap on a mic the service already knows is unsupported shows the unsupported message and starts nothing.
- **Event-by-state table (each row is a test):**

| Event | starting | listening | idle |
|---|---|---|---|
| status `listening` | -> listening | ignore (web fires it twice) | if no bound session: `engine.cancel()`; else drop |
| partial result | drop | `liveText = words` | drop |
| final result (non-empty) | drop | `_finish(auto, words)` at once (Android natural end, G5) | drop |
| status `done` | drop | native: with words `_finish(auto, liveText)`; with none wait `errorGrace` for an error, then `_finish(auto, '')`. Web: ignore | drop |
| status `notListening` | drop (the start timeout decides) | web: `_finish(auto, liveText)` at once (results precede `onend`). Native: arm `endGrace`; a final, `done` or an error inside it ends the session, else `_finish(auto, liveText)` when it expires | drop |
| benign error | drop (it cannot belong to a session that has not produced `listening`; only the time-based retry applies) | `_finish(auto, liveText)`, `empty` when no words | drop |
| permission / unsupported | `_finish(error, '')` + `failure` | `_finish(error, liveText)` + `failure` | drop |
| engine error | `_finish(error, '')` + message + telemetry | `_finish(error, liveText)` + message + telemetry (the time-based retry of D1 comes first for `error_busy`/`error_client` inside `retryWindow`) | drop |
| start timeout | `_finish(error, '')` + `engine.cancel()` | n/a | n/a |
| Stop / Send / Cancel | Cancel only: `_finish(cancelled, '')`; Stop and Send inert | `_finish(userStop\|userSend, liveText)` / `_finish(cancelled, '')` | ignore |
| hidden / dispose / preempt | `_finish(hidden\|disposed\|preempted, '')` | `_finish(.., liveText)` | ignore |
