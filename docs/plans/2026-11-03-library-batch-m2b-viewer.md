## Why the route is not opaque (the round-1 P0 of the unsplit plan)

`MaterialPageRoute` is opaque. Under an opaque top entry the overlay builds covered entries with `tickerEnabled: false` (`overlay.dart:868-889`), and flutter_riverpod 3.3.1 PAUSES every `ref.watch` subscription of a `ConsumerStatefulElement` while `TickerMode` is off (`consumer.dart:390-413`; OI-378 `docs/audit/open_issues.md:6434` records the same pause). `ActiveWorkoutScreen` and `_ExerciseCard` are both consumers, so under an opaque viewer neither would rebuild: the viewer's `+` would change the provider and no controller would be appended (`didUpdateWidget`, `exercise_card.dart:360`, is the only place the lists resize), and every card method that reads `widget.data` would read a stale snapshot. So the viewer route is a `PageRouteBuilder<void>(opaque: false, maintainState: true)` pushed on `Navigator.of(context)`, the branch navigator the screen's own page lives on: the covered screen stays live (executed spike), exactly as under the sheets already used on this screen. Consequences: only the viewer's own `Scaffold` paints (so the `Scaffold` is the ROOT of the viewer and `SafeArea` goes INSIDE its body: a `SafeArea` above it would leave transparent strips through which the covered header is SEEN; taps and semantics are already blocked by the route's own modal barrier, `routes.dart:2353-2361`, so no `BlockSemantics` of our own); the covered tile freezes through Part A's `ModalRoute.isCurrentOf(context) == false` rule with no new term (spike); the covered `ListView` can drop a card that falls outside viewport + cache (the card holds a keep-alive); the route is PAGELESS on a navigator whose page is `active-workout`, so a re-route within the branch removes it with the page and a branch switch hides it with its branch (spike); the other ways the screen's tree stops hosting the exercise are the viewer's own business (swap, removal, `data.isComplete`, below). Precedent for `opaque: false`: `lib/features/profile/widgets/profile_identity.dart:57` (it also sets a `barrierColor`).
