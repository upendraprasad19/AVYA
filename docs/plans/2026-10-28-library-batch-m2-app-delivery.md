## Review Focus (input classes the tests below pin; the reviewer checks each deliberately)

1. A row whose `media_slug` is a String but `media_version` is missing, 0, a double or a string, or whose slug holds a separator: no delivery attempt, today's plate or initials (Task 4).
2. Sign-out, account switch and delete-account run `clearAllData()`: the cache still reports the files it holds and the cap still holds (Task 5).
3. The token is stale: ONE refresh and ONE retry, process-wide cooldown, never a refresh on an absent-object 400 storm or on a 200 that is not a WebP (Task 6).
4. Two widgets ask for the same file at once, and a widget rebuilt 60 times asks once (Tasks 7, 9).
5. The cap is breached by an on-demand fetch while the plan window fills the store: window files stay (Task 7).
6. Wi-Fi drops after file 2 of a prefetch: no third request (Tasks 7, 8).
7. A truncated file, a file the OS deleted, a full disk, a browser with no IndexedDB: the view ends on the still, the bytes just paid for are not thrown away, and nothing crashes boot (Tasks 5, 7).
8. In a superset only the focused card plays (Task 11, on the real screen).
9. The software keyboard opens inside a Scaffold body (Task 12).
