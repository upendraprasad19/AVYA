## Review Focus (input classes the tests below pin; the reviewer checks each deliberately)

1. A row whose `media_slug` is a String but `media_version` is missing, 0, a double or a string, or whose slug holds a separator: no delivery attempt, today's plate or initials (Task 4).
2. Sign-out, account switch and delete-account run the REAL `clearAllData()`: the cache still reports the files it holds and the cap still holds (Task 5).
3. Concurrent changes: three `put`s at once keep three entries and an exact `totalBytes`; a fresh repository over a store that holds `ceiling - 1` bytes makes at most one more download (Tasks 5, 7).
4. The token is stale: ONE refresh and ONE retry, process-wide cooldown, never a refresh on an absent-object 400 storm or on a 200 that is not a WebP; the token never appears in any log string (Task 6).
5. Two widgets ask for the same file at once; a widget rebuilt 60 times asks once; a slow answer for exercise A landing after the user switched to B must not paint on B (Tasks 7, 9).
6. The cap is breached by an on-demand fetch while the plan window fills the store: window files stay (Task 7).
7. Wi-Fi drops after file 2 of a prefetch: no third request; the gate fails closed when connectivity cannot be read (Tasks 7, 8).
8. A truncated file, a file the OS deleted after load, a full disk, a browser with no IndexedDB or one that never answers the open: the view ends on the still, the bytes just paid for are not thrown away on-demand, a prefetch run stops instead of downloading into a store that cannot keep them, and boot is never delayed (Tasks 5, 7, 9).
9. A file that downloads but cannot be decoded is not re-downloaded on every open (Tasks 7, 9).

### Task 5: Store: files (native) or Hive lazy box (web), its own index, the cap

**Files:** Create `lib/core/services/exercise_media/exercise_media_store.dart`, `lib/core/services/exercise_media/exercise_media_webp.dart`, `test/helpers/webp_bytes.dart`; Modify `lib/core/services/hive_service.dart`; Test `test/contracts/exercise_media_store_behavioral_test.dart`, `test/contracts/exercise_media_webp_test.dart`.

**Interfaces:**
- `exercise_media_webp.dart` produces `bool isWellFormedWebp(Uint8List bytes)` (top-level; the ONE predicate the store's `read` and Task 6's client share): non-empty, `length <= 1500000` (the bucket limit, `EXERCISE_MEDIA.md:16`), bytes 0 to 3 `RIFF`, bytes 8 to 11 `WEBP`, and RIFF size (bytes 4 to 7, little endian) + 8 == `length` (that last term is dropped if Task 1's S7 found violations). `exercise_media_webp_test.dart` pins each term with a mirror (a good file passes; each single defect fails).
- `webp_bytes.dart` produces `Uint8List webpBytes(int length)` (a valid `RIFF`, size field `length - 8`, `WEBP`, then filler; `length >= 12`) and a `FakeBytesStore implements ExerciseMediaBytesStore` that yields between steps (`await Future<void>.delayed(Duration.zero)`), can be told to throw on `write`/`read`, and counts blob reads.
- Produces `abstract class ExerciseMediaBytesStore { Future<Uint8List?> read(String name); Future<void> write(String name, Uint8List bytes); Future<void> delete(String name); Future<Map<String, int?>> list(); Future<String?> readMeta(); Future<void> writeMeta(String json); }` (`list` = name -> byte length, or `null` when the backend cannot know it without reading the blob; it never returns the meta entry and never a `*.tmp`).
