## Founder rule (confirmed 2026-11-02)

A freeze is a KEPT stock. Days up to Saturday are settled FIRST (a missed scheduled day spends a freeze; Sunday is rest, free). On Monday, when the user opens the app, +1 is credited (cap 1 free / 3 PRO), irrespective of last week's misses. A user at 3 who misses 6 days keeps the streak for 3 days and loses it on the 4th; the next Monday gives +1, which covers a missed Monday (settled on Tuesday).

**Code vs rule (r1, verified):** the rollover path runs `refillIfNewWeek` (`day_rollover_service.dart:230`) BEFORE `reckonStreakDecayAndPersist` (`:247`), the reverse of the rule. The two orders differ only when the stock is 0 on Monday and Saturday was missed (rule: streak breaks, then +1; code: the Monday freeze retroactively covers Saturday). In the 2026-11-02 log a consume ran before the refill (restore-gated reckon, `train_provider.dart:2297` / `day_rollover_service.dart:166`), so the live order is path-dependent. **Decision D1 (founder): make consume-then-refill the single order on every path, or keep refill-first.** Not decided; blocks T4 only.
