fix(train): normalize logged exercise sets on swap or mismatch

When an exercise is swapped mid-active-workout from one logging type to
another (e.g., timed → weight/reps), in-flight logged sets retain the old
format, causing the edit log modal and week summary to display wrong field
values (seconds instead of reps).

Fix: Normalize all persisted sets at write time to match the resolved
logging type, clearing incompatible fields. Add one-time boot healer for
existing mismatched exlog rows.
