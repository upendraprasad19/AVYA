# ICANBEFITTER

A fitness and nutrition app for young professionals in India, built to make training and eating well simple enough to stick with.

ICANBEFITTER began as a passion project: a personal effort to build the fitness tool I wanted for myself, one that fits a busy working life and the way Indians actually eat. It has grown from there and is still built with the same care.

**Try it:** [app.icanbefitter.com](https://app.icanbefitter.com)

---

## What it does

- **Train:** personalised workout plans that adapt as you progress.
- **Eat:** food logging built around Indian foods.
- **Coach:** an AI coach for day-to-day questions and guidance.
- **Track:** progress, streaks and health data in one place.

---

## Built with

Flutter (Android and web), Supabase, and a local-first design so the app works offline.
