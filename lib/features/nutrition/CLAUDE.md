## What lives here

`lib/features/nutrition/` owns the 🥗 Nutrition tab + Diet Plan flow.

Screens / sections:

- `nutrition_screen.dart` — top targets + today's macros + 2-tab Log Food (AI text + Scan meal) + saved meals + water + today's meals card (from saved diet plan). Each meal-slot's "LOG TO {SLOT}" tap opens `log_food_sheet.dart` with `lockedSlot` set; the free-floating "LOG FOOD" button (left half of `LogActionRow`) opens it unlocked. **LOG HYDRATION** (right half, 2026-11-01) opens `showHydrationSheet` (`hydration_sheet.dart`), a bottom sheet that hosts the unchanged `HydrationCard` (water glasses, +250/+500 ml, urine status) — the card is no longer inline on the page, so the logged meals sit directly under the two buttons. Pinned by `test/contracts/nutrition_screen_layout_test.dart` + `test/widgets/log_action_row_and_hydration_sheet_test.dart`.
- `log_food_sheet.dart` — the single bottom sheet for logging food (5 tabs: AI / Scan / Cart / Barcode / Search), replacing the retired `log_to_slot_sheet.dart` (deleted 2026-09-20, obs 5). `showLogFoodSheet(context, {initial, lockedSlot})`; when `lockedSlot` is set it seeds `mealTypeProvider` to that slot on open via a deferred `addPostFrameCallback` and retitles to "LOG TO {SLOT}" — the title then TRACKS the live provider value for the rest of the sheet's lifetime (corrected 2026-09-20, diagnose e1c5b8: previously read the static `lockedSlot` param and went stale if a tab's own selector moved the write destination).
- `food_logger_section.dart` — AI text analysis ("2 chapatis and dal") via `ai-proxy` with `type: 'food_text_analysis'` (gemini-3.1-flash-lite) → AI breakdown card. NOT a `food-text-analysis` Edge Function — no such function exists. **Mic (2026-11-14):** a `_MicTile` at the end of the field row (tap to start, the words form live in the field behind anything already typed; the field grows to 6 lines and each live write jumps it to its end, OI-348 Landing 3e `c7e3a2`; the tile is Stop, ANALYSE & LOG reads SEND, `LISTENING m:ss` + `CANCEL` under the field), on the same shared `SpeechInputService` as the coach. Messages (a refused microphone, no words heard, too short, the PRO daily cap) show INLINE under the field (`_notice`, key `speech_notice`), NEVER as a SnackBar: the Log sheet is a modal bottom sheet with no Scaffold, so a snackbar is drawn on the page behind it. A Stop commit puts the cursor back in the field, a hidden tab or a preemption does not (`speechEndWantsFocus`). The mic runs the SAME usage gate as ANALYSE before it listens (`_passesUsageGate`); a spoken meal is the existing `food_text_analysis` call, counted against its existing units (no new unit, no local parser).
- `scan_meal_section.dart` — photo capture → `ai-proxy` with `type: 'scan_meal'` (gemini-3.1-flash-lite vision, server cap combined with cart_auditor: free 4/day, PRO 20/day since migration 153) → editable result via `_ScanResultEditor`.
- `cart_auditor_section.dart` — paste / photograph grocery cart → AI macro/cost audit.
- `diet_plan_screen.dart` — generated diet plan + PDF export. Generation goes through `CuratedDietPlanGenerator.generatePlan` (or the legacy `DietPlanGenerator` when `DietPlanFlags.curatedEnabled` is false); swaps through `swapAlternatives` (the sheet itself is `widgets/diet_plan_swap_sheet.dart` since Unit 3b-1b, ceiling; the whole swap flow, the strategy shift and the totals row builder live in the part file `screens/diet_plan_screen_swap.dart` since diet chart v3, which Gate 43 does not count; the row itself is `widgets/diet_plan_totals_row.dart`); Regenerate moves the seed (`dietPlanSeed`). The PDF document is built by `services/diet_plan_pdf.dart` `buildDietPlanPdf` (moved out to keep the screen under the 800-line ceiling, Unit 2a); the food-type control is a dropdown in `widgets/diet_plan_settings_row.dart` (Edit Profile uses the shared `FoodTypeChips`).
- `water_section.dart` — `WardGlassGrid` 8-cell tracker.
- `nutrition_history_screen.dart` — Nutrition History (`/nutrition/history`): since-day-one trend chart, consistency heatmap, hit-rates, macro split, calories vs weight, patterns, top foods, insight lines, day sheet. See the `nutrition_history` row.

for `nlog_*` Hive rows + `nutrition_logs` cloud) + `nutrition_read_service.dart`.
